# Avatar

The `Avatar` component represents an avatar with different variants (Avatar, Icon) and sizes (XS, S, M, L).

## Usage

To incorporate the Avatar component into your application, simply provide the necessary inputs to the component. The Avatar component offers a range of customizable properties such as type, size, background color, border color, border weight, and border radius, allowing you to tailor the appearance of the avatar to suit your application's requirements.

## Default

{/* ! default avatar */}

CSS styles for `Avatar` component:

```css
/* Avatar styles */
.mas-avatar {
  /* Avatar styles here */
}
.mas-avatar_container {
  /* Avatar elements container styles here */
}
```
