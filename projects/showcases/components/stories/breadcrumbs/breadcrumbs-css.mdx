# Breadcrumbs

Breadcrumb is a type of contextual navigation that helps the user know where they are within the site and navigate within the site. It's a secondary navigation element.

<nav class="mas-breadcrumbs_nav sb-unstyled">
  <div class="mas-breadcrumb-item">
    <a>Accueil</a>
  </div>
  <div class="mas-breadcrumb-item">
    <a>Gestion des utilisateurs</a>
  </div>
  <div class="mas-breadcrumb-item">
    <a>EUDE Valerie</a>
  </div>
</nav>

CSS styles for `Breadcrumbs` component:

```css
.mas-breadcrumbs_nav {
  /* styles here */
}
.mas-breadcrumb-item {
  /* styles here */
}
.mas-breadcrumb_overflow {
  /* styles here */
}
```
