# Icon Button

## Introduction

The `MasIconButton` is an action component that works like the other buttons but its design is simpler, which allows it to be used when you need to add actions that take up less space or when grouping several actions together in a restricted layout.

## Default

<button class="mas-icon-button mas-icon-button_shape--square mas-icon-button_variant--primary mas-icon-button_size--medium">
<i class="mas-icon mas-icon-alone mas-arrow-square-out-outlined mas-arrows--outlined"></i>
</button>

CSS styles :

```css
.mas-icon-button {
  /* styles here */
}
```
