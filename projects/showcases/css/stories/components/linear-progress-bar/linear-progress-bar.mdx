# Progress bar

## Overview

A `MasLinearProgressBar` serves as an indicator that signifies the acknowledgment of the user's request and signifies that the application is actively advancing towards fulfilling the requested task. These visual elements are designed to keep users informed about the current state of ongoing processes, provide estimates for the duration of a task, and indicate when a request is in the process of execution.
