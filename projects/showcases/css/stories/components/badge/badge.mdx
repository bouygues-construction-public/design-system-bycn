# Badge

A badge is a visual indicator used to display notification or status.

## Usage

- The badge is a visual indicator.
- It can be used alone or with an icon.
- It gives additional information to an element.

## Default

<div class="container">
  <div class="mas-badge mas-badge_size--large ">
    <span class="mas-badge_content mas-badge_type--number sb-unstyled">99+</span>
  </div>
</div>

CSS styles for `Badge` component:

```css
/* Badge styles */
.mas-badge {
  /* Badge styles here */
}
```
